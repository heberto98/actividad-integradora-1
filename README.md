# Actividad Integradora 1 - SARS-CoV-2

Para correr todo:

```
python main.py
```

| Archivo | Parte |
|---|---|
| `parte1_genes.py` | 1. Indices de los genes M, S y ORF1AB en el genoma |
| `parte2_palindromos.py` | 2. Palindromo mas largo de cada gen |
| `parte3_proteinas.py` | 3. Proteinas en el genoma |
| `parte4_mutaciones.py` | 4. Mutaciones Wuhan vs Texas |

Cada parte es una funcion (`parte1()`, `parte2()`, ...) que `main.py` llama en orden.

## Archivos de datos (en esta misma carpeta)

- `SARS-COV-2-MN908947.3.txt` (Wuhan 2019)
- `SARS-COV-2-MT106054.1.txt` (Texas 2020)
- `gen-M.txt`, `gen-S.txt`, `gen-ORF1AB.txt`
- `seq-proteins.txt`
